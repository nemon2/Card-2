# Игральные карты Dota 2

Карты 2–10, оформленные под Dota 2. Каждая карта сохраняет свой концепт,
обрамление у всех одно.
Готовый PDF для печати на A4: **[`out/game-cards-a4.pdf`](out/game-cards-a4.pdf)**

## Единое обрамление

Одинаково на всех девяти картах:

- **Масть — логотип Dota.** Он стоит в углах вместо ♥ и больше нигде червового
  значка нет.
- **Крупный номинал в стиле Dota** — Grenze Gotisch, угловатые готические цифры,
  высота 7,6 мм (на обычной карте ~5 мм). Красный, цвет логотипа.
- **Золотая двойная рамка** с угловыми скобками и подписью `DOTA 2` сверху.
- Белая карта, без фона.
- Пипсы в нижней половине **не переворачиваются** — портреты и иконки везде
  стоят «лицом вверх», как в твоих референсах.

## Что в PDF

- **1 страница A4**, 9 карт сеткой 3×3.
- Размер карты — **63,5 × 88,9 мм** (2.5″ × 3.5″), стандартный покерный формат,
  тот же, что у Bicycle и у карт PokerClub.
- Карты лежат вплотную, соседние режутся одним разрезом. По краю карты — тонкая
  серая линия реза, по полям листа — метки реза.
- Графика векторная, файл ~27 КБ. Пиксель-арт рисуется прямоугольниками, поэтому
  печатается резко на любом DPI, без «мыла».

## Как печатать

1. **A4, масштаб 100%.** В диалоге печати выберите «Реальный размер» /
   «Actual size», а **не** «Вписать в страницу» — иначе размер уедет.
2. Бумага: плотный матовый картон **250–300 г/м²**.
3. Резать по серым линиям, ориентируясь на метки реза на полях.
4. По желанию — скруглить углы угловым дыроколом радиусом 3 мм.

Внутри карты запас **4 мм**: даже если разрез уйдёт на миллиметр-полтора,
ничего не обрежется.

## Сборка

```bash
pip install -r requirements.txt
python3 build.py                       # -> out/game-cards-a4.pdf
```

Полезные ключи:

```bash
python3 build.py --singles -o one.pdf  # по одной карте на страницу
python3 build.py --ranks 7 10          # только выбранные номиналы
python3 build.py --gap 2               # зазор 2 мм между картами
python3 build.py --no-marks            # без меток реза и подписи
```

Старые три масти (Hollow Knight ♠, Clash Royale ♣, Apex Legends ♦) лежат в коде
нетронутыми, со своими знаками и персонажами, и собираются отдельно:

```bash
python3 build.py --suits spades clubs hearts diamonds
```

Проверки геометрии:

```bash
python3 -m pytest tests/
```

## Структура

```
build.py             CLI
deck/config.py       размеры карты и листа, шрифты, цветовые утилиты
deck/icons.py        знаки игр, включая логотип Dota
deck/dotaart.py      сферы, иконки способностей, кристаллы, посох + разводка по картам
deck/pixelart.py     пиксельные портреты героев
deck/themes.py       цвета, шрифты, рамки и раскладка мастей
deck/card.py         отрисовка одной карты и раскладка пипсов
deck/sheet.py        вёрстка A4 и метки реза
deck/suits.py        классические значки мастей (для старых мастей)
deck/sketch.py       «рукописные» линии (для старых мастей)
deck/parts.py        детали фигур (для старых мастей)
deck/characters.py   персонажи (для старых мастей)
assets/fonts/        шрифты (SIL OFL, см. assets/fonts/README.md)
```

## Как добавить карту или героя

- Пиксельный портрет — сетка символов в `deck/pixelart.py`, палитра рядом.
  `.` прозрачный; одинаковые пиксели в строке склеиваются в один прямоугольник.
- Что на какой карте — словарь `_RANK_ART` в `deck/dotaart.py`:
  `(вид, функция-выбора-по-индексу, множитель размера)`.

## Оформление

Вся графика нарисована здесь векторными путями и пиксельными сетками по
референсам. Dota 2 и её символика принадлежат Valve; колода сделана как подарок
для личного использования и не предназначена для продажи.
