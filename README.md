# Игральные карты Dota 2

Печатный лист A4 из присланных карт. Картинки используются **как есть** —
ничего не перерисовано и не растянуто.
Готовый PDF: **[`out/game-cards-a4.pdf`](out/game-cards-a4.pdf)**

## Что внутри

8 карт: **3, 4, 5, 6, 7, 8, 9, 10**. Карта **2** не присылалась — девятое место
на листе пустое, пришлёшь картинку, положу её туда.

Исходники лежат в `assets/cards/src/` (`03.png` … `10.png`), имя файла = номинал.

## Что делается с картинкой

Присланные кадры сняты по-разному: часть — в край, часть лежит на сером фоне
студии, где-то с тенью, где-то с колодой карт позади. С каждой картинкой
делается ровно три вещи:

1. **Обрезка до самой карты.** Порог берётся от статистики рамки кадра
   (перцентили яркости по краям), а не от одного замеренного цвета — иначе
   градиентный фон подмешивается в маску. Строки маски заполняются от первого
   до последнего попадания, чтобы тёмная графика внутри светлой карты не
   пробивала в ней дыры.
2. **Зачистка кромки** — остатки фона в скруглённых углах и тонкие полоски по
   краю перекрашиваются в собственный цвет карты.
3. **Приведение к формату карты** добавлением полей её же цветом. Пропорции не
   меняются, ничего с карты не срезается.

Разрешение на выходе — 268–484 DPI при ширине 63,5 мм. Тест не даёт опуститься
ниже 250.

## Лист

- **1 страница A4**, сетка 3×3, карта **63,5 × 88,9 мм** (2.5″ × 3.5″) —
  стандартный покерный формат, как у Bicycle и у карт PokerClub.
- Карты вплотную: соседние режутся одним разрезом. По краю карты — тонкая серая
  линия реза, по полям листа — метки реза.

## Как печатать

1. **A4, масштаб 100%.** Выберите «Реальный размер» / «Actual size», а **не**
   «Вписать в страницу», иначе размер уедет.
2. Бумага: плотный матовый картон **250–300 г/м²**.
3. Резать по серым линиям, ориентируясь на метки реза на полях.
4. По желанию — скруглить углы угловым дыроколом радиусом 3 мм.

## Сборка

```bash
pip install -r requirements.txt
python3 build.py                        # -> out/game-cards-a4.pdf
```

```bash
python3 build.py --ranks 5 6 7          # только выбранные карты
python3 build.py --gap 2                # зазор 2 мм между картами
python3 build.py --no-marks             # без меток реза и подписи
```

## Добавить карту

Положите файл в `assets/cards/src/` с именем по номиналу (`02.png`, `11.png`,
…) и пересоберите. Больше ничего делать не нужно — обрезка и подгонка
автоматические.

## Нарисованная колода

В репозитории осталась отдельная, полностью векторная колода (Hollow Knight ♠,
Clash Royale ♣, Dota 2 ♥, Apex Legends ♦) — со своими знаками, пиксель-артом и
персонажами. Она не участвует в сборке выше и собирается отдельно:

```bash
python3 build.py --vector --suits spades clubs hearts diamonds
```

Проверки:

```bash
python3 -m pytest tests/
```

## Структура

```
build.py              CLI
deck/imagecards.py    обрезка и подгонка присланных картинок
deck/sheet.py         вёрстка A4 и метки реза
deck/config.py        размеры карты и листа, шрифты
assets/cards/src/     исходные картинки карт
out/                  готовый PDF
```

Остальные модули (`card.py`, `icons.py`, `dotaart.py`, `pixelart.py`,
`characters.py`, `parts.py`, `sketch.py`, `suits.py`, `themes.py`) относятся к
нарисованной колоде.
