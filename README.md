# Игральные карты в стиле игр — Dota 2

Карты 2–10 масти ♥, оформленные под Dota 2. Один шаблон на все девять карт.
Готовый PDF для печати на A4: **[`out/game-cards-a4.pdf`](out/game-cards-a4.pdf)**

## Шаблон

- **Масть — логотип Dota.** Он же стоит в углах вместо ♥, он же используется
  как пипсы. Классического червового значка на карте нет.
- **Номинал крупный и стилизован под Dota** — Grenze Gotisch, высота цифры
  7,6 мм (для сравнения: на обычной карте 5 мм). Красный, цвет логотипа.
- **Золотая двойная рамка** с угловыми скобками и подписью `DOTA 2` сверху.
- **Пасхалка внизу** — свой герой на каждой карте, нарисованный пером.
- Фона нет: карта белая.

| 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 | 10 |
|---|---|---|---|---|---|---|---|---|
| Pudge | Juggernaut | Crystal Maiden | Axe | Invoker | Sniper | Lina | Anti-Mage | Phantom Assassin |

Тузы и рубашку вы делаете сами.

## Что в PDF

- **1 страница A4**, 9 карт сеткой 3×3.
- Размер карты — **63,5 × 88,9 мм** (2.5″ × 3.5″), стандартный покерный формат,
  тот же, что у Bicycle и у карт PokerClub.
- Карты лежат вплотную, соседние режутся одним разрезом. По краю карты — тонкая
  серая линия реза, по полям листа — метки реза.
- Графика векторная, файл ~21 КБ.

## Как печатать

1. **A4, масштаб 100%.** В диалоге печати выберите «Реальный размер» /
   «Actual size», а **не** «Вписать в страницу» — иначе размер уедет.
2. Бумага: плотный матовый картон **250–300 г/м²**.
3. Резать по серым линиям, ориентируясь на метки реза на полях.
4. По желанию — скруглить углы угловым дыроколом радиусом 3 мм.

Внутри карты запас **4 мм**: даже если разрез уйдёт на миллиметр-полтора,
ни пипс, ни номинал, ни персонаж не обрежется.

## Сборка

```bash
pip install -r requirements.txt
python3 build.py                       # -> out/game-cards-a4.pdf (только Dota)
```

Полезные ключи:

```bash
python3 build.py --singles -o one.pdf  # по одной карте на страницу
python3 build.py --ranks 7 10          # только выбранные номиналы
python3 build.py --gap 2               # зазор 2 мм между картами
python3 build.py --no-marks            # без меток реза и подписи
```

Остальные три масти (Hollow Knight ♠, Clash Royale ♣, Apex Legends ♦) остались
в коде со своими знаками и персонажами, но под новый шаблон ещё не доведены.
Собрать их можно так:

```bash
python3 build.py --suits spades clubs hearts diamonds
```

Проверки геометрии:

```bash
python3 -m pytest tests/
```

## Структура

```
build.py             CLI
deck/config.py       размеры карты и листа, шрифты, цветовые утилиты
deck/icons.py        знаки игр, включая логотип Dota
deck/suits.py        классические значки мастей (для остальных мастей)
deck/sketch.py       «рукописные» линии с дрожанием
deck/parts.py        общие детали фигур: плащ, наплечники, рога, оружие
deck/characters.py   персонажи, по одному на карту
deck/themes.py       цвета, шрифты и рамки мастей
deck/card.py         отрисовка одной карты и раскладка пипсов
deck/sheet.py        вёрстка A4 и метки реза
assets/fonts/        шрифты (SIL OFL, см. assets/fonts/README.md)
```

## Как добавить тузы

1. В `deck/config.py` добавьте `"A"` в `RANKS`.
2. В `deck/card.py` добавьте в `PIP_LAYOUTS` строку `"A": [(C, 0.5)]` — один
   крупный логотип по центру (размер через `pip_scale` темы).
3. В `deck/characters.py` добавьте персонажа под ключом `"A"`.

Тогда на масть станет 10 карт и на лист 3×3 они не влезут: меняйте
`ROWS`/`COLS` в `deck/config.py` или печатайте в два листа.

## Оформление

Знаки и персонажи нарисованы здесь векторными путями по референсам из игр.
Dota 2 и её символика принадлежат Valve; колода сделана как подарок для
личного использования и не предназначена для продажи.
